# Deployment Guide\n\n## IBICO OSMS Deployment Instructions\n\n### Prerequisites\n- Docker & Docker Compose (recommended)\n- Or: Node.js 18+, .NET 8 SDK, SQL Server 2019+\n- Git\n\n## Option 1: Docker Deployment (Recommended)\n\n### Build Docker Images\n```bash\n# Frontend\ndocker build -t ibico-osms-frontend:latest ./frontend\n\n# Backend\ndocker build -t ibico-osms-backend:latest ./backend\n\n# Database\ndocker build -t ibico-osms-db:latest ./database\n```\n\n### Docker Compose\n```yaml\nversion: '3.8'\nservices:\n  database:\n    image: mcr.microsoft.com/mssql/server:2019-latest\n    environment:\n      SA_PASSWORD: YourPassword123!\n      ACCEPT_EULA: Y\n    ports:\n      - \"1433:1433\"\n    volumes:\n      - sqldata:/var/opt/mssql\n\n  backend:\n    image: ibico-osms-backend:latest\n    ports:\n      - \"5000:80\"\n    environment:\n      ConnectionStrings__DefaultConnection: \"Server=database;Database=IBICO_OSMS;User Id=sa;Password=YourPassword123!;\"\n      Jwt__Secret: \"your-secret-key-here-change-in-production\"\n    depends_on:\n      - database\n\n  frontend:\n    image: ibico-osms-frontend:latest\n    ports:\n      - \"3000:3000\"\n    environment:\n      REACT_APP_API_URL: http://localhost:5000/api\n    depends_on:\n      - backend\n\nvolumes:\n  sqldata:\n```\n\n### Run with Docker Compose\n```bash\ndocker-compose up -d\n```\n\n## Option 2: Manual Deployment\n\n### Database Setup\n\n1. **Create Database**\n```sql\nCREATE DATABASE IBICO_OSMS;\nUSE IBICO_OSMS;\n```\n\n2. **Run Migration Scripts**\n```bash\ncd database/schema\n# Execute all SQL scripts in order\n```\n\n### Backend Deployment\n\n1. **Build**\n```bash\ncd backend/IBICO.OSMS.Api\ndotnet restore\ndotnet build -c Release\n```\n\n2. **Run**\n```bash\ndotnet run --configuration Release\n```\n\n### Frontend Deployment\n\n1. **Install Dependencies**\n```bash\ncd frontend\nnpm install\n```\n\n2. **Build**\n```bash\nnpm run build\n```\n\n3. **Serve**\n```bash\n# Using a static server\nnpm install -g serve\nserve -s dist\n```\n\n## Environment Configuration\n\n### Backend (appsettings.json)\n```json\n{\n  \"ConnectionStrings\": {\n    \"DefaultConnection\": \"Server=localhost;Database=IBICO_OSMS;User Id=sa;Password=YourPassword123!;\"\n  },\n  \"Jwt\": {\n    \"Secret\": \"your-very-long-secret-key-change-in-production\",\n    \"Issuer\": \"IBICO.OSMS\",\n    \"Audience\": \"IBICO.OSMS.Users\",\n    \"ExpirationMinutes\": 60\n  },\n  \"Cors\": {\n    \"AllowedOrigins\": [\"http://localhost:3000\", \"https://yourdomain.com\"]\n  }\n}\n```\n\n### Frontend (.env.local)\n```\nREACT_APP_API_URL=http://localhost:5000/api\nREACT_APP_ENV=development\n```\n\n## Production Deployment\n\n### AWS Deployment\n\n1. **Frontend on S3 + CloudFront**\n   - Build and upload `dist/` to S3 bucket\n   - Create CloudFront distribution\n   - Configure domain with Route53\n\n2. **Backend on ECS/App Service**\n   - Container image on ECR\n   - ECS cluster with auto-scaling\n   - RDS for SQL Server database\n   - Load balancer for traffic distribution\n\n### SSL/TLS Configuration\n- Use AWS Certificate Manager or Let's Encrypt\n- Enable HTTPS on CloudFront and load balancer\n- Update CORS settings for production domain\n\n## Monitoring & Logging\n\n### Application Insights\n```csharp\n// In Startup.cs\nservices.AddApplicationInsightsTelemetry();\n```\n\n### Log Levels\n- Debug: Development\n- Information: Production\n- Warning: Issues that need attention\n- Error: Failures\n\n## Health Checks\n\n```bash\n# API Health\ncurl http://localhost:5000/api/health\n\n# Database Connection\ncurl http://localhost:5000/api/health/db\n```\n\n## Rollback Procedures\n\n1. **Database Rollback**\n   - Keep previous migration scripts\n   - Run rollback scripts if needed\n\n2. **Application Rollback**\n   - Keep previous Docker images tagged\n   - Revert to previous version using docker-compose\n\n## Maintenance\n\n### Database Maintenance\n- Daily: Backup\n- Weekly: Index maintenance\n- Monthly: Statistics update\n\n### Security Updates\n- Monitor security advisories\n- Apply patches promptly\n- Update dependencies monthly\n\n## Support & Troubleshooting\n\nFor issues, check:\n- Application logs\n- Database connectivity\n- Environment variables\n- Network/firewall rules\n- API endpoint availability\n
