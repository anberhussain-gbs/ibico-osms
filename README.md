# IBICO Organization Structure Management System (OSMS)\n\n## Overview\n\nIBICO OSMS is a production-ready enterprise web application for dynamic organization chart management, employee hierarchy tracking, and organizational analytics.\n\n## Features\n\n✅ **Dynamic Organogram** - Interactive organization chart with zoom, pan, search, filter\n✅ **Employee Management** - Comprehensive employee profiles and management\n✅ **Dashboard & Analytics** - Executive dashboards with advanced analytics\n✅ **Department View** - Multi-department organization view\n✅ **Search System** - Global search across employees, departments, designations\n✅ **Drag & Drop Hierarchy** - Update reporting structure in real-time\n✅ **Vacancy Management** - Track and visualize vacant positions\n✅ **Transfer History** - Complete audit trail of organizational changes\n✅ **Role-Based Access Control** - Multi-tier authorization system\n✅ **Excel Import/Export** - Bulk data import and export capabilities\n✅ **Mobile Responsive** - Fully responsive design for all devices\n✅ **Dark Mode Support** - Professional dark and light themes\n\n## Technology Stack\n\n### Frontend\n- React 18.x\n- TypeScript\n- React Flow\n- Tailwind CSS\n- Shadcn UI\n- Zustand (State Management)\n- Recharts (Data Visualization)\n\n### Backend\n- ASP.NET Core 8\n- Entity Framework Core\n- JWT Authentication\n- Role-Based Authorization\n\n### Database\n- SQL Server\n- Entity Framework Core Migrations\n\n## Project Structure\n\n```\nibico-osms/\n├── frontend/                 #
